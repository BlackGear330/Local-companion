# AI Companion

Личный ИИ-компаньон, работающий полностью локально на компьютере пользователя (без отправки данных в облачные сервисы). 

## Что это за проект
Программа представляет собой консольного собеседника с характером, который использует локальную языковую модель (через LM Studio). Проект создается как долгосрочный компаньон, способный запоминать контекст общения и извлекать полезные факты о пользователе/активности ПК для использования их в будущих диалогах.

## Текущие возможности
На данный момент реализована базовая архитектура ядра:
- **История диалогов**: все сообщения сохраняются в локальную базу данных SQLite. При перезапуске программа продолжает последний активный диалог.
- **Управление диалогами**: поддерживаются консольные команды для создания новых веток общения (`/new`), просмотра списка (`/list`), переключения (`/open`) и архивации (`/archive`).
